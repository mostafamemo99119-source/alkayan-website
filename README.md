# El Kayan Hub

"قم ببناء نظام ويب متكامل وفائق الفخامة بمستوى عالمي لشركة مساحات عمل مشتركة (Co-working Space) باسم 'الكيان'. المشروع يتكون من واجهة أمامية فاخرة للزوار، ولوحة تحكم خلفية للمدير. الموقع باللغة العربية (RTL) بالكامل ومتجاوب مع جميع الشاشات.

أولاً: الهوية البصرية والتصميم (UI/UX)

الألوان: خلفية سوداء عميقة (Dark Charcoal/Deep Black) مع تفاصيل ولمسات باللون الذهبي الفاخر، ونصوص بيضاء.

الستايل: استخدم التأثير الزجاجي (Glassmorphism / Backdrop Blur) لجميع الكروت، الشريط العلوي، والنوافذ المنبثقة.

الحركة: تأثيرات دخول ناعمة وتفاعل أنيق عند مرور الماوس بحيث تضيء الحواف بالذهبي الخافت.

ثانياً: واجهة الزوار (الواجهة الأمامية)

الشريط العلوي (Navbar): زجاجي ثابت يضم شعار 'الكيان'، وروابط الأقسام.

الواجهة الافتتاحية (Hero): عنوان فخم، نصوص ترحيبية، وأزرار زجاجية بحواف ذهبية.

قسم الفيديو: مساحة مخصصة لعرض فيديو YouTube داخل إطار زجاجي بإضاءة خلفية ذهبية.

قسم المميزات: كروت زجاجية بخدمات المكان (إنترنت فائق السرعة، قاعات ذكية، ضيافة).

قسم الغرف والمساحات (Dynamic Section): كروت زجاجية تعرض الغرف (الصورة، السعة، السعر). عند النقر على الكارت تفتح نافذة (Modal) زجاجية بتفاصيل الغرفة وزر 'طلب حجز' يوجه لـ WhatsApp. يجب أن تقرأ هذه الكروت بياناتها وصورها ديناميكياً من قاعدة البيانات وليس أكواداً ثابتة.

ثالثاً: لوحة تحكم الإدارة (Admin Dashboard & CMS)

أنشئ لوحة تحكم مخفية ومحمية بصفحة تسجيل دخول (Admin Login) خاصة بي كمدير.

وفر فيها نظام إدارة محتوى (CMS) يتيح لي بوضوح: إضافة غرف ومساحات جديدة، رفع وتغيير صور كل غرفة، وتعديل الأسعار والوصف والسعة في أي وقت.

اربط لوحة التحكم بالواجهة الأمامية بحيث ينعكس أي تعديل أقوم به فوراً على كروت الغرف في الموقع.

وفر شاشة إحصائيات بسيطة في لوحة التحكم تعرض إجمالي الغرف المسجلة."
